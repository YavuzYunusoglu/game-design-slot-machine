# Game Design Slot Machine / Fikirhane

A bilingual, dependency-free game idea generator for designers and developers. It automatically starts in Turkish when the browser language is Turkish and in English for all other languages.

## Run locally

Open `index.html` in any modern browser. No build step or dependency installation is required.

## Features

- English and Turkish interface with automatic language detection
- 8 creative categories and more than 110 billion combinations
- Lock individual reels for controlled idea generation
- Animated slot machine with optional sound effects
- Save ideas locally and copy them to the clipboard
- Press `Space` for a quick spin
- Responsive layout, accessible controls and reduced-motion support
